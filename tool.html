FBNeo Cheat -> EmulatorJS

Chuyển file cheat FBNeo (.ini / .cht / .dat / .xml) thành arcade.json đúng chuẩn EmulatorJS.

Hoặc kéo thả file cheat vào đây

Hỗ trợ: .ini (FBNeo gốc, 1 game 1 file), .cht (RetroArch), cheat.dat (MAME), .xml (MAME XML). Mã cheat ra dạng ĐỊA_CHỊ=GIÁ_TRỊ (hex), nhiều chỗ ghi nối bằng dấu +, vd 107156=75+107157=30.

Kết quả: Chưa chuyển đổi
1. Chọn file hoặc thư mục cheat (hoặc kéo thả vào khung trên). 2. Bấm "Chuyển đổi". 3. Bấm "Tải arcade.json" rồi up file đó lên thư mục cheats/ trên kho (cùng chỗ với EJS_cheatPath).
